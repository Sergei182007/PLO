# FASTA Reader

Python-модуль для работы с биологическими последовательностями в формате FASTA.

Реализованы два класса:

- **`Seq`** — хранение и анализ одной последовательности (нуклеотидной или белковой)
- **`FastaReader`** — чтение FASTA-файлов с поддержкой больших файлов через генератор

---

## Возможности

- Чтение FASTA-файлов любой размера (используется генератор)
- Красивый вывод последовательности в формате FASTA (по 60 символов в строке)
- Определение длины последовательности
- Автоматическое определение алфавита ('nucleotide' / 'protein' / 'unknown')
- Проверка, является ли последовательность белковой или нуклеотидной
- Корректная обработка ошибок (неверный тип, пустой файл, неправильный формат и т.д.)
